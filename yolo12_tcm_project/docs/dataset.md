# 数据集说明

## 数据格式

本项目使用标准 YOLO 检测格式：

```text
images/
  xxx.jpg
labels/
  xxx.txt
```

每一行标签格式：

```text
class_id x_center y_center width height
```

其中坐标均为 0~1 归一化值。

## 划分

默认按 7:2:1 划分：

- train：模型训练
- val：训练过程调参和早停
- test：最终泛化性能评估

测试集不得参与训练和调参。

## 检查项

`scripts/validate_yolo_dataset.py` 检查：

- 图片损坏
- 标签缺失
- 类别编号越界
- bbox 未归一化
- bbox 超出边界
- 空标签
- 重复图片
- 重复标注行
- 孤立标签
- 类别样本分布

## 分类数据集临时转换

若原始数据只有分类目录，没有边界框标注，可用整图框临时转换跑通流程。但报告必须说明：

- 该方式只验证工程链路。
- 该方式不等价于真实目标检测数据。
- 真实项目应补充人工标注或半自动标注。
