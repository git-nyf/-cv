## 第 5 页：基础模型结构

标题：基础模型结构：YOLOv12n-cls

页面内容：

- 基础模型：`yolo12n-cls.yaml`
- 任务类型：classification
- 输入尺寸：224 x 224
- 类别数：92
- 训练方式：迁移学习，`pretrained: true`
- 优化器：AdamW
- GPU 训练：100 epoch

模型结构说明：

- Backbone 提取边缘、纹理、形状等视觉特征。
- Neck/特征融合结构增强多尺度表达。
- Classification Head 输出 92 类概率分布。

## 第 6 页：核心算法与工程流程

标题：核心流程设计

页面内容：

完整流程：

1. 原始分类目录读取：`train/<类别>`、`val/<类别>`
2. strict JPEG 数据清洗：格式统一、损坏图跳过、图片可读性检查
3. 类别一致性审计：确认原始 93 类与 strict 92 类差异
4. 重复与泄漏审计：检查 train/val exact duplicate 与跨类别重复
5. YOLOv12 分类训练
6. 独立验证与 Top-k 推理
7. FastAPI 服务封装
8. Vue 前端展示

布局：

- 下半部分分成两块：
  - 数据质量控制：清洗、审计、泄漏检查
  - 模型推理服务：模型权重、API、前端
